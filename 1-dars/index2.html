Mening Kartochkam

Salom! Bu mening shaxsiy web-kartochkam. Men hozirda HTML va CSS dasturlash tillarini qunt bilan o'rganmoqdaman.

Web-dasturlash orqali chiroyli, qulay va interaktiv saytlar yaratish mening asosiy maqsadlarimdan biridir.

Kirimli texnologiyalar:

  • HTML - Strukturani yaratish
  • CSS - Dizayn va stillar berish
  • JavaScript - Interaktivlik qo'shish
